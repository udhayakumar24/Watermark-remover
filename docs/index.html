Watermark Remover

Remove watermarks from video on your own device. It erases only the text — never the face behind it — tracks moving logos frame by frame, and reconstructs what's hidden with neural inpainting.

100% local & offline LaMa AI inpainting Moving-watermark tracking Mobile-friendly PWA

Why it's different

🎯

Erases only the text

A tight glyph mask isolates just the watermark strokes, so a face, mouth, or product behind the text is left bit-for-bit untouched.

🧠

AI reconstruction

Where a stroke crosses a mouth or eye, LaMa (or fast diffusion) rebuilds that tiny gap from the surrounding skin — the feature stays.

🎞️

Tracks moving logos

Per-frame template tracking follows a watermark as it pans, so removal stays locked on across the whole clip.

🔒

Nothing leaves your device

All processing is local — no uploads, no accounts, no cloud. Your footage never touches a server.

See it work — text across a mouth

Measured on this frame (mean abs error in the mouth region): leaving the text = 21.7, old box-based removal = 29.7 (worse!), text-only AI removal = 3.2.

Run it yourself

git clone https://github.com/udhayakumar24/Watermark-remover.git
cd Watermark-remover
pip install -r requirements.txt
python scripts/fetch_model.py   # one-time, 88 MB (Apache-2.0)
./run.sh                        # or: python app.py

Then open http://localhost:8000 on your phone or laptop, drop in a video, draw the box, and render. Works on Windows too via run.bat.

This page is a static project site. The remover itself is a Python app that runs on your machine — it can't run inside GitHub Pages, by design, so your videos stay private.
